# ML Lab

ML Lab is an interactive linear regression visualizer. It shows real batch gradient descent states as a line fits a dataset. Public visitors can replay three bundled synthetic examples without starting the backend; the administrator can upload CSV or JSON data, choose two columns, and train a new model on the Python API.

The original requirements and implementation plan are in [build.md](build.md).

## What is implemented

- One-variable linear regression written from scratch in Python, with X/Y standardization, batch gradients, conversion back to original units, MSE, MAE, R², and up to 126 genuine training snapshots.
- Three synthetic public examples: study hours and exam score, advertising spend and sales, and years of experience and salary. Their replay histories are generated by the backend trainer and bundled into the frontend.
- React/TypeScript workspace with Apache ECharts scatterplot, fitted line, synchronized loss chart and metrics, playback, speed control, scrubbing, zoom and reset.
- Admin-only CSV/JSON upload, data preview, numeric column selection, training settings, login, and logout.
- FastAPI endpoints for health, login, token verification, and protected training. Argon2 password hashes, 30-minute signed tokens, bounded requests, validation, limited concurrency, rate limits, and exact-origin CORS.

## Architecture

```text
Browser → Vercel React frontend → Render FastAPI backend → CPU gradient descent
       ↳ bundled example snapshots (no API needed for public playback)
```

The backend is stateless. Uploaded files are parsed in the browser and only selected numeric `(x, y)` pairs are sent to the API. Neither server nor browser stores a dataset or token persistently. No pretrained model is needed: every admin training run initializes standardized slope and intercept at zero and computes gradients from the selected points.

## Local setup

### Backend

From `backend/`:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python scripts\create_password_hash.py
.venv\Scripts\python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Create `backend/.env` from `backend/.env.example`. Paste the generated **hash** into `ADMIN_PASSWORD_HASH` and the generated random value into `JWT_SECRET`. These are different values. Keep `.env` private; it is ignored by Git. Set `ALLOWED_ORIGINS` to the exact frontend origins that will call the API.

```powershell
.venv\Scripts\python -m uvicorn app.main:app --reload --env-file .env --port 8000
```

Check `http://localhost:8000/api/health` for `{"status":"ok"}`. The interactive API docs are disabled because this API is intentionally small.

### Frontend

From `frontend/`:

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

Open `http://localhost:5173`. The sample replay works even when the backend is off. For admin login and training, start the backend too. A sleeping backend can take time to respond; the UI shows a wake-up message after eight seconds and allows a 90-second request.

## Data format

CSV:

```csv
hours,score
1,25
2,35
3,48
4,62
5,75
```

JSON:

```json
[{"hours":1,"score":25},{"hours":2,"score":35},{"hours":3,"score":48}]
```

Files must be at most 5 MB and contain at most 5,000 rows. The selected columns need at least two finite numeric pairs with differing X values. Invalid or missing rows are excluded and counted in the UI. The API repeats validation and accepts only values within ±1e12, permitted learning rates, and permitted epoch counts.

## How the learning animation works

For standardized coordinates, the model predicts `ŷ = mx + b`. Each epoch computes `MSE = Σ(ŷ−y)²/n`, `dm = 2Σ((ŷ−y)x)/n`, and `db = 2Σ(ŷ−y)/n`, then subtracts the learning-rate-scaled gradients from `m` and `b`. The trainer records actual states at epoch 0, the final epoch, and evenly spaced epochs between them. For display it converts the coefficients to original units:

```text
display slope     = normalized slope × y scale / x scale
display intercept = y mean + normalized intercept × y scale − display slope × x mean
```

The displayed line, equation, MSE, MAE, R², current epoch, and highlighted loss point all use the **same selected snapshot**. The chart may visually transition between states, but the underlying values are actual trained states. R² is shown as undefined for a constant target.

To regenerate bundled public histories after changing the algorithm or examples:

```powershell
cd backend
.venv\Scripts\python -m scripts.generate_examples
```

Commit the updated `frontend/src/data/examples.json` with the code change.

```powershell
cd backend

cd ..\frontend
npm ci
npm run build
npm run lint
npm test
# With both local servers running and a disposable local test password:
$env:ML_LAB_TEST_PASSWORD = "your-local-test-password"

```

The browser smoke tests use an installed Google Chrome and require both local servers. The test password is a disposable local credential.

The backend tests cover gradients, prediction, standardization, convergence, large values, constant data, deterministic snapshots, authentication, authorization, invalid input, request size, and rate limiting. The frontend build runs TypeScript checks. Browser-level checks should cover public replay, admin login, upload, training, and mobile layout.

## Deployment preparation

Deployment is intentionally left to the project owner.

### Vercel

- Import this repository and set **Root Directory** to `frontend`.
- Build command: `npm run build`; output directory: `dist`.
- Set `VITE_API_BASE_URL` to the HTTPS URL of the Render service, with no trailing slash.
- The public frontend contains no password, hash, or signing secret.

### Render

- Create a Python Web Service from this repository with **Root Directory** `backend`.
- Build command: `pip install -r requirements.txt`.
- Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.
- Health check path: `/api/health`.
- Set `ADMIN_PASSWORD_HASH` to the output of `python scripts/create_password_hash.py`.
- Set `JWT_SECRET` to a separate random secret of at least 32 characters, for example from `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
- Set `ALLOWED_ORIGINS` to the exact Vercel production origin and any explicit local development origins, separated by commas. Do not use `*` or a trailing path.

The owner plans to handle Render availability monitoring with Uptime Robot. No keep-alive ping is built into the app. The public replay is independent of backend availability.

## Security and limitations

The admin token remains in React memory and is lost on refresh. It expires after about 30 minutes. Logout discards it immediately in the browser; tokens already issued are not centrally revoked because there is no database. In-memory rate limits reset when Render restarts and are not a substitute for edge-level abuse protection. This app is designed for a single admin and small demonstration workloads. It does not provide a public training API, multi-user accounts, nested JSON mapping, or persistent file storage. Three example datasets are synthetic and should not be interpreted as real study, sales, or salary evidence.

The code separates the trainer, API, dataset parser, and charts so additional algorithms can later be added with their own validated training routes, result types, and visualization components. Version 1 deliberately exposes only linear regression.
