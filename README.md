# ML Lab

ML Lab is an interactive visualizer for Linear Regression, K-Means Clustering, KNN Regression, and KNN Classification. It shows real gradient descent or centroid states as a model learns, and highlights the neighboring points behind KNN predictions. Public visitors can explore bundled synthetic examples without starting the backend; the administrator can upload CSV or JSON data and run new training on the Python API.

The original requirements and implementation plan are in [build.md](build.md).

## What is implemented

- One-variable linear regression written from scratch in Python, with X/Y standardization, batch gradients, conversion back to original units, MSE, MAE, R², and up to 126 genuine training snapshots.
- A final-model X input that predicts Y locally from the trained slope and intercept, independently of playback.
- K-Means written from scratch in Python, with scaled Euclidean distance, deterministic initialization, bounded iterations, and genuine centroid/assignment snapshots. Two synthetic cluster examples are bundled for public replay.
- KNN regression written from scratch in TypeScript. It averages the Y values of the K nearest X values, highlights those neighbors, and runs locally with no backend request or training epochs.
- KNN classification written from scratch in TypeScript. It finds nearest neighbors using two numeric features, tallies their category labels, and shows the vote on the chart. Two distinct labeled synthetic examples are bundled.
- Three synthetic public examples: study hours and exam score, advertising spend and sales, and years of experience and salary. Their replay histories are generated by the backend trainer and bundled into the frontend.
- React/TypeScript workspace with Apache ECharts scatterplot, fitted line, synchronized loss chart and metrics, playback, speed control, scrubbing, zoom and reset.
- Admin-only CSV/JSON upload, data preview, numeric feature and class label selection, training settings, login, and logout.
- FastAPI endpoints for health, login, token verification, and protected training. Argon2 password hashes, 30-minute signed tokens, bounded requests, validation, limited concurrency, rate limits, and exact-origin CORS.

## Architecture

```text
Browser → Vercel React frontend → Render FastAPI backend → CPU training
       ↳ bundled regression and cluster snapshots, local KNN queries (no API needed for public exploration)
```

The backend is stateless. Uploaded files are parsed in the browser and only selected numeric `(x, y)` pairs are sent to the API for Linear Regression or K-Means. Neither server nor browser stores a dataset or token persistently. KNN queries run in the browser and do not send uploaded points to the API. No pretrained model is needed.

## Local setup

### Backend

From `backend/`:

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python scripts\create_password_hash.py
.venv\Scripts\python -c "import secrets; print(secrets.token_urlsafe(48))"
```

Create `backend/.env` from `backend/.env.example`. Paste the generated **hash** into `ADMIN_PASSWORD_HASH` and the generated random value into `JWT_SECRET`. These are different values. Keep `.env` private; it is ignored by Git. Set `ALLOWED_ORIGINS` to the exact frontend origins that will call the API.

```powershell
.venv\Scripts\python -m uvicorn app.main:app --reload --env-file .env --port 8000
```

Check `http://localhost:8000/api/health` for `{"status":"ok"}`. The interactive API docs are disabled because this API is intentionally small.

### Frontend

From `frontend/`:

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

Open `http://localhost:5173`. The sample replay works even when the backend is off. For admin login and training, start the backend too. A sleeping backend can take time to respond; the UI shows a wake-up message after eight seconds and allows a 90-second request.

## Data format

CSV:

```csv
hours,score
1,25
2,35
3,48
4,62
5,75
```

JSON:

```json
[{"hours":1,"score":25},{"hours":2,"score":35},{"hours":3,"score":48}]
```

Files must be at most 5 MB and contain at most 5,000 rows. The selected numeric values must be finite and within ±1e12. Linear Regression requires varying X values; K-Means requires at least K distinct points; KNN Regression requires at least K usable pairs. Invalid or missing rows are excluded and counted in the UI. The API repeats validation for backend training.

For **KNN Classification**, provide two numeric feature columns and a third categorical label column. For example:

```csv
petal_length,petal_width,species
1.4,0.2,Setosa
1.6,0.3,Setosa
4.0,1.2,Versicolor
4.4,1.4,Versicolor
```

At least K usable labeled rows, two distinct feature pairs, and two to eight distinct classes are required. Labels may be text or numeric codes and must be at most 60 characters. The X feature, Y feature, and class label must be three different columns. Extra columns are ignored after selection.

## How the learning animation works

For standardized coordinates, the model predicts `ŷ = mx + b`. Each epoch computes `MSE = Σ(ŷ−y)²/n`, `dm = 2Σ((ŷ−y)x)/n`, and `db = 2Σ(ŷ−y)/n`, then subtracts the learning-rate-scaled gradients from `m` and `b`. The trainer records actual states at epoch 0, the final epoch, and evenly spaced epochs between them. For display it converts the coefficients to original units:

```text
display slope     = normalized slope × y scale / x scale
display intercept = y mean + normalized intercept × y scale − display slope × x mean
```

The displayed line, equation, MSE, MAE, R², current epoch, and highlighted loss point all use the **same selected snapshot**. The chart may visually transition between states, but the underlying values are actual trained states. R² is shown as undefined for a constant target.

To regenerate bundled public histories after changing the algorithm or examples:

```powershell
cd backend
.venv\Scripts\python -m scripts.generate_examples
```

Commit the updated `frontend/src/data/examples.json` with the code change.
The same command also regenerates `frontend/src/data/cluster_examples.json` from the K-Means trainer.

## Other algorithms

- **K-Means:** Select 2–5 clusters and at most 10, 20, or 30 iterations. Each iteration assigns every point to the nearest center in scaled X/Y coordinates and then moves each center to its assigned points' mean. The timeline shows actual centers, assignments, and inertia. Training uses the protected `/api/kmeans/train` route and shares the existing request, rate, and concurrency limits.
- **KNN regression:** Choose K from 1, 3, 5, 7, or 9, then enter X. The prediction is the arithmetic mean of the selected neighbors' Y values. Equal-distance ties use dataset order. It has no fitted coefficients or training timeline; queries run in the browser.
- **KNN classification:** Choose K from 1, 3, 5, 7, or 9, then enter values for both numeric features. Distances are Euclidean after dividing each feature by its range in the selected data. The majority class wins; a tied vote goes to the class of the closest tied neighbor. The chart shows the class colors, selected neighbors, and predicted point. It has no training timeline or backend request.

## Deployment preparation

Deployment is intentionally left to the project owner.

### Vercel

- Import this repository and set **Root Directory** to `frontend`.
- Build command: `npm run build`; output directory: `dist`.
- Set `VITE_API_BASE_URL` to the HTTPS URL of the Render service, with no trailing slash.
- The public frontend contains no password, hash, or signing secret.

### Render

- Create a Python Web Service from this repository with **Root Directory** `backend`.
- Build command: `pip install -r requirements.txt`.
- Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.
- Health check path: `/api/health`.
- Set `ADMIN_PASSWORD_HASH` to the output of `python scripts/create_password_hash.py`.
- Set `JWT_SECRET` to a separate random secret of at least 32 characters, for example from `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
- Set `ALLOWED_ORIGINS` to the exact Vercel production origin and any explicit local development origins, separated by commas. Do not use `*` or a trailing path.

The owner plans to handle Render availability monitoring with Uptime Robot. No keep-alive ping is built into the app. The public replay is independent of backend availability.

## Security and limitations

The admin token remains in React memory and is lost on refresh. It expires after about 30 minutes. Logout discards it immediately in the browser; tokens already issued are not centrally revoked because there is no database. In-memory rate limits reset when Render restarts and are not a substitute for edge-level abuse protection. This app is designed for a single admin and small demonstration workloads. It does not provide a public training API, multi-user accounts, nested JSON mapping, or persistent file storage. All seven example datasets are synthetic and should not be interpreted as real study, sales, salary, flower, fruit, or customer evidence.

The code separates the trainers, API, dataset parser, and charts so each algorithm has its own validated result and visualization. The original Version 1 specification limited the app to Linear Regression; this was expanded at the owner's request.
